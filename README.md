# Jaguar (Pvt) Ltd. website

B2B marketing site and HR careers CMS for a vertically integrated knitwear manufacturer.

**Developer handbook (as-built):** [handbook/README.md](./handbook/README.md)

Original planning specs (not current IA): [docs/00-PROJECT-OVERVIEW.md](./docs/00-PROJECT-OVERVIEW.md)

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Copy `.env.example` to `.env.local` for email and HR CMS. Details: [handbook/02-getting-started.md](./handbook/02-getting-started.md).

## Stack

Next.js 16 (App Router), TypeScript, Tailwind CSS v4, next-intl (`en` default plus `ar` `zh` `es` `fr` `de`).
